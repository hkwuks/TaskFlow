# Repository standards and TaskFlowDocs root
> Task version: v1
> Status: completed

## Goal

Give each repository a discoverable place for code, commit, design, and development-process rules, while making `TaskFlowDocs/` the single default root for TaskFlow artifacts. When work targets a Git remote or pull request, let the Agent discover and incorporate repository-host PR rules into the same standards index.

## Version boundary

This archived v1 defined discovery of existing standards only. It was superseded because it omitted user-guided creation of missing standards and did not follow its own Task-version transition before extending that behavior.
