# Spec — 工作树复用改名
> Task version: v1
> Status: planning

## Boundaries and responsibilities
`reuse-worktree` 负责验证、交接、目录移动、日志和恢复；调用方确认空闲并从工作树外运行。Git 负责移动和更新工作树登记。文档说明新路径及恢复入口。

## Interface and data flow
目标目录为当前目录的同级目录，目录名取目标分支去掉类型前缀后的任务描述。开始和恢复旧任务都适用。验证目标是单个安全路径组件；冲突在任何交接写入前拒绝。交接日志记录原路径和目标路径，移动后更新脚本当前根路径，成功输出最终路径。

## Invariants and failure semantics
不覆盖已有路径，不丢弃忽略文件或任务证据；原有基准、归档、索引和子模块检查继续有效。移动前后失败均保留可定位日志；恢复根据实际 Git 登记确定当前路径并恢复原路径及原分支，出现冲突或不一致时停止以供检查。移动完成前后均应可从存在的路径调用恢复。

## Tests and trade-offs
扩展既有交接夹具，覆盖成功、冲突、故障及恢复；不增加通用路径配置。Windows 文件句柄可能阻止移动，应返回清晰错误。
